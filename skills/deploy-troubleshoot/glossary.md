# 术语表：部署排障

| 术语 | 含义 |
| --- | --- |
| 定界（Bisect） | 把问题定位到某一层（硬件/驱动/系统/容器/依赖/服务/应用）的动作。 |
| 最小化复现 | 剥离无关组件后仍能触发问题的最短路径；触发不稳定时记录触发率。 |
| 假设（Hypothesis） | 基于事实的可验证推断；未验证前不是结论。 |
| 反向验证 | 从候选根因推导其他应有现象并检查；全成立才确认根因。 |
| workaround | 绕过问题的临时方案；必须标注临时性与适用条件，不等于根因解决。 |
| L0-L3 | 命令授权分级：只读 / 本地可逆 / 改变环境 / 影响运行系统。 |
| 命令五元组 | 命令文本、退出码、stdout、stderr、执行位置。证据的最小单位。 |
| driver mismatch | 驱动与 CUDA/容器工具链版本不兼容类故障的统称，具体以版本矩阵为准。 |
| 镜像 digest | 镜像内容的不可变标识；排障时比 tag 可靠。 |
| 环境快照 | 按 environment-snapshot 标准采集的环境事实集合，带采集时间。 |
