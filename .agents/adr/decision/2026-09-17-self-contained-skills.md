# ADR 决定：组件自包含

## 背景

ruokee-agent-kit ADR 2026-08-24 要求组件自包含，避免安装时断链或依赖缺失。

## 决定

每个 Skill 目录必须自包含。禁止 Skill 内文件引用、书面路径引用、执行前置规则依赖组件目录外文件。必要规则复制最小版本进组件内。

## 真实替代项

- 允许跨 Skill 引用（DRY 但脆弱）
- 中央共享库（复杂度更高）

## 后果

- ✓ 任一 Skill 可单独复制、分发、安装
- ✓ 升级一个 Skill 不影响其他
- ✗ 某些规则（如环境采集命令）会在多个 Skill 重复

## 重审条件

出现大量规则重复导致维护负担时。
