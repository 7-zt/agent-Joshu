# ADR 决定：L0-L3 命令授权分级

## 背景

部署排障中某些命令破坏性强（重启服务、删除文件、改配置）。参考 ruokee 的授权边界设计。

## 决定

deploy-troubleshoot 使用 L0-L3 四级授权：

- L0（只读）：可直接执行
- L1（本地可逆）：说明意图后执行
- L2（改变环境）：用户确认后执行
- L3（影响运行系统）：必须明确授权 + 回退方法

用户请求「排查」不自动授权 L2/L3。

## 真实替代项

- 二级（只读/写入）
- 每个命令都问（太繁琐）
- 全授权（不安全）

## 后果

- ✓ 安全与效率平衡
- ✓ 风险分级清晰
- ✗ 需要 Agent 准确分级命令

## 重审条件

分级粒度不够或过细时。
