# 工作规则索引

`.agents/rule/` 说明本仓库的工作方式。

## 两层文档

- `.agents/adr/`：长期决定，回答「为什么」。
- `.agents/rule/`：工作规则，回答「怎么做」。

`AGENTS.md` 只保留导航和非显然约束，不复制这两层的内容。历史日期文档默认保留原文，不作为当前规则入口。允许格式调整与死链清理；其余修改只在维护者明确提出时进行。

## 冲突处理

用户当前指令优先于本目录规则。规则与 `.agents/adr/` 冲突时，先确认哪一层需要更新：长期选择变化新增 ADR，操作方式变化改 rule。不要只改其中一层让文档表面一致。

`.agents/rule/` 中的规则：

- [代码管理](./code-management.md)：分支、提交、检查、合并和任务材料。
- [测试](./testing.md)：测试目标、边界、组织、命名、断言和覆盖。
- [Python 风格](./code-style-python.md)：命名、格式、类型、结构体、依赖、配置和功能开关。
- [项目结构](./project-structure.md)：仓库布局、memtrace 包、组件落位、依赖边界、bootstrap 部署与记录去向。
- [工程取舍](./coding-notes.md)：优先级、显式、克制、契约先行、抽象成本。
- [文档撰写](./document-writing.md)：分层、标题、格式、语言、引用、职责检查和 Issue 正文。
